01 / DSA Code Execution IDE

Multi-Language Code Runner & Problem Sheets

The TechPrep AI Code Runner allows students to solve curated Data Structures & Algorithms (DSA) problems in 4 programming languages: C++, Python 3, Java 17, and Node.js JavaScript.

  • Execution Sandbox: Simulates compiling, testcase assertions, time complexity metrics, and memory bounds.
  • Topic Sheets: Grouped into Sliding Window, Two Pointers, Dynamic Programming, Graphs, Trees, and Priority Queues.
02 / AI Resume Designer & ATS Matcher

Real-Time ATS Parsing & LaTeX Formatting

The ATS Resume Designer analyzes resume bullet points against recruiter algorithms used by Workday, Greenhouse, and Lever.

  • Single-Column Template Validation: Verifies layout readability to eliminate parsing crashes.
  • Keyword Density Suggestions: Identifies missing technical stack keywords (e.g., PostgreSQL, System Design, REST APIs).
03 / Campus Placement Drive Tracker

Campus Eligibility & Pipeline Tracking

Filter campus recruitment drives based on package (LPA), minimum CGPA cutoffs, backlog rules, and application status (Applied, Shortlisted, Interview Round, Offer Extended).

04 / Admin Console & Site Management

Tech Hub Administration, Bulk Importers & System Logs

Administrators can seed custom quizzes via Excel/Word/TXT importers, monitor student directory telemetry, manage FAQs, export/restore full database backups, and inspect live security audit logs.
